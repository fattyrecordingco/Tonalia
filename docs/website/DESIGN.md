# Tonalia website

Host: GitHub Pages in fattyrecordingco/Tonalia. The user's hosting choice overrides the Sites skill's default hosting service. No separate hosted Site or account is created.

Purpose: help someone choose the right installer, make their first useful edit, and keep their recording and project safe. Include the existing working browser editor, without presenting desktop-only sharing as a browser feature.

## Design

Palette: studio navy #171d29, recessed ink #10151f, raised slate #252d3e, warm white #f1f3f7, spectrogram apricot #edb083, soft violet #b7a0d3. Muted text #aab6c9. Colours come from the audio workspace and its frequency display.

Type: locally hosted DM Sans, shared with the app. Large, quiet headings; normal sentence case. Body text stays under 70 characters per line. Code is reserved for commands people actually need to enter.

Layout: broad opening with left-aligned heading and real app screenshot; a three-column OS chooser; alternating screenshot and short task explanation; a separate guide with a sticky contents list. On small screens everything follows one reading order. Screenshots can be opened at full size using an accessible dialog.

```
Brand             Downloads  Guide  Open editor  GitHub
See your sound.   [actual app screenshot]
Keep your original.
[Download] [Open browser editor]
Windows           Mac                 Linux
Five real installer links, grouped by operating system
Select a sound    [selection screenshot]
[export screenshot] Save an edit you can revisit
First-edit guide / shortcuts / questions / footer
```

Review: avoid a repeated feature-card grid, animated waveform decoration, invented testimonials and vague professional-quality claims. The actual frequency display is the visual focus. The OS chooser is a comparison, not marketing cards. Guide numbering represents real ordered steps. No generated or simulated app screenshots.

## Copy

Use the labels people see in Tonalia, then explain them: a layer is a saved change; a project keeps editable changes; an exported WAV is the finished audio. Explain frequencies as low/deep and high/bright before using Hz. State current limits where they affect a choice. Explain unsigned/unnotarized installation prompts without telling people to disable system protections.
