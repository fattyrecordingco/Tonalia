to finished audio.

Start here if you’re new to Tonalia. The screenshots use a built-in practice recording, so you can follow along without risking a session.

Click any app screenshot to see a larger version. The app is designed for a computer screen.

Install Tonalia

Choose your computer below. Before updating an older version, save your project and close Tonalia.

Windows 11

These steps are for an Intel or AMD 64-bit computer. Check Settings → System → About → System type if you’re unsure. There isn’t a native Windows ARM installer yet.

  1. Download the Windows installer

    It’s the file ending in setup.exe. You only need this file.

  2. Open the downloaded file. If Windows shows an unknown-publisher message, check that it came from the official Tonalia release linked here. Only continue if you trust that download; work-managed computers may block it.
  3. Follow the setup window. Choose Next, read the licence and choose I Agree, then continue to Install. You can keep the suggested folder.
  4. Choose Finish, then open Tonalia from the Start menu or its shortcut.

The installer includes the extra Windows display component Tonalia needs, so you don’t have to find it separately.

Uninstall or check the download

Remove Tonalia through Settings → Apps → Installed apps. Your original recordings and saved project files stay in their folders.

To check a download, get the checksum list and compare the number for your file with this PowerShell command. A matching number means the file matches this release. 

Get-FileHash .\Tonalia_0.4.1_windows_x64_setup.exe -Algorithm SHA256

Mac

Open Apple menu → About This Mac. If it lists an Apple M-series Chip, choose Apple Silicon. If it lists an Intel Processor, choose Intel. You need macOS 13 or later.

Download for Apple SiliconDownload for Intel Mac
  1. Open the downloaded .dmg file. If a licence agreement appears, read and accept it to open the disk image.
  2. Drag Tonalia into Applications in the window.
  3. Eject the disk image, then open Applications → Tonalia.

If macOS won’t open it

This development build hasn’t been checked and notarized by Apple. After trying to open Tonalia, you may be able to allow this specific app in System Settings → Privacy & Security → Open Anyway. Only do this for a download you trust. Don’t turn off your Mac’s security protections.

Apple’s guide explains these messages. A managed Mac may still block the app.

Uninstall or check the download

Delete Tonalia from Applications to uninstall. Keep your recordings and project files. To check the Apple Silicon download against the checksum list, use Terminal: 

shasum -a 256 Tonalia_0.4.1_macos_apple_silicon.dmg

For an Intel Mac, use the Intel filename instead.

Linux

These downloads are for 64-bit Intel or AMD computers. Running uname -m should show x86_64. There isn’t a Linux ARM package yet.

Ubuntu / Debian

Ubuntu 22.04 or later is the tested build baseline. Other Debian-based systems may need additional setup.

Download the Debian package

Open a terminal in the folder containing the download and run:

sudo apt install ./Tonalia_0.4.1_linux_amd64.deb

Enter your password if asked. Then open Tonalia from your applications menu. The package manager may need internet to install missing system libraries; Tonalia itself runs offline once installed.

AppImage

Download the AppImage

In the download folder, make it runnable and open it:

chmod +x Tonalia_0.4.1_linux_x86_64.AppImage
./Tonalia_0.4.1_linux_x86_64.AppImage

If it reports a FUSE error, try:

./Tonalia_0.4.1_linux_x86_64.AppImage --appimage-extract-and-run

The AppImage still needs a compatible Linux desktop and audio system. It isn’t guaranteed to work on every distribution.

Uninstall or check the download

Remove the Debian package with sudo apt remove tonalia, or delete the AppImage. Check the Debian package against the checksum list with: 

sha256sum Tonalia_0.4.1_linux_amd64.deb

When the app opens, it looks like the workspace below. All editing steps in this guide apply to both desktop and browser unless a step says otherwise.

Make your first edit

This quick exercise turns down a whistle in a practice recording. It takes a few minutes.

  1. Open the practice recording.

    In a new Tonalia window, choose Explore a calibration session. If a recording is already open, use Project → Calibration session. Save any edits you want to keep before changing recordings.

    “Calibration session” is the app’s name for its generated practice sound. To use your own recording instead, choose Open WAV. This version opens WAV files, not MP3s.

  2. Select the whistle.

    Choose Frequency rectangle in the top toolbar. In the Edit panel, set Start to 6.000 s and End to 7.000 s. Set Low frequency to 2500 Hz and High frequency to 4000 Hz. Press Enter after each value.

    These values describe the high whistle in the practice sound. The correct values for another recording will be different.

  3. Turn it down.

    Keep the starting −18 dB setting, or choose −6 dB for a smaller change. Negative numbers make the selected sound quieter. Give the change a useful Layer name, then choose Create gain layer.

    A layer is a saved change to the recording. “Gain” here simply means making it louder or quieter.

  4. Listen and compare.

    Click near the start of the changed area on the time ruler, then press Space to play. Compare Original and Result at the bottom. Try Removed to hear what the edit is taking away. Switching a layer or changing playback mode may stop playback; press Space again.

  5. Keep your work.

    Use Project → Save project to keep the change editable. Choose Export audio to make a new WAV. The saving section explains why you may want both.

Find your way around

The coloured picture is called a spectrogram: it shows which sounds happen at each moment. You don’t need to understand the maths to use it.

Across the picture: time
Left is earlier. Right is later. The ruler shows minutes and seconds.
Up the picture: pitch
Deep sounds sit lower; bright, high sounds sit higher. Hz measures how quickly a sound vibrates. Higher numbers mean higher frequencies.
Brighter colour: stronger sound
Dim purple areas are quieter. Brighter orange and pale areas are stronger. Changing the display brightness only changes the picture.
Left: your changes
The source is your original recording. Each layer beneath it is a separate, reversible change.
Right: the controls
Edit sets a selection and volume change. Restore offers clean-up tools. Analyze shows measurements. Share is for desktop local-network sessions.
Bottom: listening
Play, stop, move back, repeat a selected time range, compare versions and set your listening level.

Stereo recordings have a separate left and right display. The Channels control lets you affect both or just one.

Select the part you want to change

Drop a mono or stereo WAV into the editor to open it, or choose Open WAV. Save any current project before replacing its source.

Selection tools
Tool When to use it How
Time selection T A whole moment, across all pitches. Drag from its start to its end.
Frequency rectangle M A steady whistle, tone or small block of sound. Drag around its time and pitch range.
Lasso L A sound with an uneven outline. Draw around it and release to close the outline.
Spectral brush B A narrow trail or a few scattered spots. Paint over the sound. Adjust size, opacity and hardness in the toolbar. The live outline shows its footprint.
Pan canvas H Moving around without drawing a selection. Drag horizontally or vertically. You can also drag with the middle mouse button.

Use the Start, End, Low frequency and High frequency fields for an exact rectangle. Editing those bounds turns the selection into a rectangle.

Time feather and Frequency feather soften the edges of an edit. Larger values make a more gradual transition. Brush strokes have their own soft edges. A change can reach slightly beyond the drawn edge because sound analysis uses short overlapping slices.

Zoom with the Hz buttons above the spectrum. Use the up/down arrows, the frequency slider on its right edge, or scroll over the Hz ruler to move vertically. Alt + Shift + scroll also pans frequency. In Display, set View low frequency and View high frequency for exact limits.

New brush strokes are continuous: fast movements leave no gaps and repeated pointer events do not build up opacity. Hardness sets how sharply the brush edge falls away. Older saved strokes keep their original shape and opacity.

Press Escape to clear the selection. Use Channels to choose both sides of a stereo recording or one side only.

Work with layers

A layer keeps one change separate from the original. A useful name, such as “Whistle at 6 seconds”, is easier to find later than “Edit 3”.

  • Switch an edit off: click its eye button. Click again to switch it on.
  • Change a volume edit: click its layer, adjust the setting in Edit, then choose Update layer.
  • Add another change to the same area: choose Use selection for a new layer before creating the next volume edit.
  • Change the order: use the up/down buttons beside a layer. The order matters when one change affects what a later change receives.
  • Remove an edit: use its bin button. The source recording stays untouched.
  • Undo or redo: use the top-right arrows, or the keyboard shortcuts below.

Clean-up layers are separate too, but their settings can’t yet be edited in place. Delete and recreate a clean-up layer to change its settings.

Save a project file regularly. Tonalia keeps recent recovery checkpoints too, but they don’t replace a backup.

Clean up a recording

Select the affected part, open Restore, choose an operation and set its controls. Choose Create restoration layer, then listen to Result and Removed. Start gently: unwanted sound can overlap the sound you want to keep.

Noise reduction: learn a noise profile

  1. Select a passage containing only the noise, from 2048 samples to 10 seconds.
  2. Choose Noise reduction (captured profile) and Capture noise profile. The profile is measured from the original, separately for each channel.
  3. Select the audio to clean, or choose Select entire recording.
  4. Adjust Noise sensitivity and Maximum reduction, then choose Create restoration layer.

Compare Result and Removed. This works best for steady noise; a profile containing wanted sound can remove it too. The profile is saved with the layer.

Spectral gate: reduce quiet background sound

Choose Spectral gate. Gate threshold sets the level below which sounds are reduced. Maximum reduction limits how much quieter they become. A lower reduction is gentler. It can also affect quiet parts of speech or music, so compare often.

Harmonic hum attenuation: reduce a steady electrical buzz

Choose this for a low, repeating hum. Try a Hum fundamental of 50 Hz or 60 Hz, depending on the recording. It also reduces related higher tones. Set a small maximum reduction first. This early tool has fairly broad frequency bands and may affect nearby musical notes.

Short-click interpolation: fill a tiny damaged moment

Select a click no longer than 0.010 seconds (10 milliseconds), with intact audio on both sides. This tool draws a short connection between the neighbouring samples. It uses the whole pitch range in the selected time, not just the frequencies you outlined. It isn’t a general-purpose repair brush.

Offline neural speech denoise: reduce noise around speech

This is an experimental, included speech clean-up model. It runs locally and doesn’t download a model or send your recording away. Your file must be 48 kHz; look at the source information on the left to check. Neural strength runs from 0 (no change) to 1 (full effect).

It uses the whole pitch range for the selected time and can affect desired speech or music. This version supports one neural speech layer per project. It processes stereo channels separately. Listen before keeping the result.

Separate sounds into WAV tracks

This workspace requires the installed desktop app. Open a WAV and choose Separate sounds in the top bar. The browser editor provides spectral editing and noise reduction, but cannot run these optional AI packs.

Set up once

Install Python 3.11 or later if it is missing, reopen Tonalia, then use Install AI pack in the separation window. Tonalia creates its own environment and downloads the selected models. The three packs contain about 1.1 GiB of model assets in total, plus Python dependencies. Setup needs internet and disk space; later inference runs locally. Your recording is not uploaded.

Let the analysis choose

  1. Choose Auto separate and set the time range you want to analyse.
  2. Choose Analyse and separate. Detection identifies likely sources; music is routed to instrument separation and other sounds to targeted extraction.
  3. Use Preview to listen to each generated track. Spectral cleanup reduces shared energy and bleed. The residual retains unassigned audio.
  4. Open a track in the editor to refine it, or export the tracks into a new folder.

Choose a more specific tool

  • Find sounds: analyse the recording for suggestions. Choose Extract to create audio for a detected source. Inspect region only moves the spectral view.
  • Music stems: split vocals, drums, bass, guitar, piano and other instruments. An absent instrument may produce a nearly silent track.
  • Isolate a sound: enter up to eight descriptions for targeted extraction. Suggestions are measured detector results, not example presets.
  • Tiny clicks: find brief transients and extract their spectral energy, keeping continuous background sound in the residual.

Detection scores are model estimates, not guarantees. Raise the minimum score to reject weaker suggestions; quiet or unfamiliar sounds can be missed. A lighter click may be found as a transient without being identified as a lighter. Separation can leave bleed or remove desired detail. Keep the residual and compare with the original. These are separate WAV files, not a multitrack timeline. Processing is limited to ten minutes per job.

Play and compare

Press Space or the play button to listen. Press Space again to stop. Click the time ruler to move the playhead; the playhead shows where playback will start.

Original
Your recording before the layers.
Result
Your recording with enabled layers applied.
Removed
The difference between them. If you hear important speech or music here, the edit may be taking away too much.

Select a time range and turn on the repeat button to loop it. Keep your listening level comfortable. The volume slider at the bottom changes what you hear; it does not change the exported file.

Changing layers stops playback so you can hear a consistent version when you start again. Clean-up can take a moment to prepare on slower computers.

Save a project. Export a WAV.

These do different jobs. Keep both if you want a finished audio file and a way to revise your work.

Save project

Keeps your layers, selections used by those layers, and view. It does not contain the audio.

Choose Project → Save project, or press Ctrl/Cmd + S. Keep the .tonalia.json file and the unchanged original WAV together.

Export audio

Makes a new WAV of the Result, Removed difference, or Original. The Signal menu defaults to your monitor mode.

Choose Export audio, pick a signal, range and precision, then choose Export WAV. Use a new filename.

Export just what the layers removed

Attenuate the material with a layer, choose Removed and export it. Export Result separately to keep the cleaned recording. Removed is original minus the complete enabled layer stack, including gains and feathering. Bypass other layers to export one layer’s difference. At partial attenuation it contains the attenuated amount, not the whole sound inside the outline. At 64-bit precision, Result plus Removed reconstructs the decoded original to floating-point precision.

Which export setting?

32-bit float WAV is a sensible starting point if the next app supports it. 64-bit float WAV keeps more numerical precision and makes a larger file. This version doesn’t export 16-bit WAV or MP3; check what the next app accepts. Tonalia keeps the original sample rate and number of channels.

The display settings and listening-volume slider are left out of the export. Very loud edits can exceed a normal playback system’s range even though a float file can store them. Listen and check levels before delivering a file.

Open a saved project

  1. Choose Project → Open project.
  2. Select the .tonalia.json file.
  3. If asked, select its unchanged original WAV. Tonalia checks that it is exactly the same recording before loading the edits.

Exporting a finished WAV doesn’t replace saving a project. A finished WAV won’t bring your editable layers back.

Recover recent work

Open History, find a checkpoint and choose Restore. You may need to select the original WAV again. Tonalia keeps up to 20 recent local checkpoints after you pause editing for about 1.5 seconds.

History doesn’t copy your audio. A crash before the next checkpoint, a storage problem or clearing app data can lose the latest work. Keep explicit project backups.

Check your recording

Open Analyze to inspect the sound and the original file’s levels. Moving around the recording changes the frequency view.

Sample peak
The largest stored sample level. Near 0 dBFS means near the usual full-scale playback level. This isn’t a true-peak meter.
RMS
A rough average signal level. It isn’t a broadcast loudness reading.
DC
A measure of whether the waveform sits off centre.
Correlation
How similar the two stereo channels are. Near +1 means very similar; near −1 means they strongly oppose each other. It isn’t a complete phase-analysis tool.

Analysis FFT changes the detail of the picture, up to 16,384 samples. Larger values separate close frequencies more clearly but blur fast changes in time. Changing this setting, the frequency scale or display brightness doesn’t change the audio edit.

Keys, mouse and trackpad

Scroll over the sound picture to zoom around the pointer. Pinch on a trackpad to zoom too. Hold Shift while scrolling to move through time; a horizontal trackpad scroll does the same. Hold Alt while scrolling to zoom the frequency range. Scroll over the Hz ruler, use the right-edge slider, or hold Alt + Shift while scrolling to pan vertically after zooming.

On a Mac use Command (⌘) where Windows and Linux use Ctrl. Shortcuts leave text fields alone while you’re typing.

Edit with someone on the same network

This experimental feature is in the installed desktop app. It shares edits between computers on a trusted local network. It isn’t an internet meeting room, and it doesn’t send audio files.

Host a session

  1. Each person opens an identical copy of the original WAV. Save any existing project first.
  2. The host opens Share, enables Allow private LAN connections for other computers, and chooses Host session. Leaving that box off allows connections only on the same computer.
  3. Enter the host computer’s private network address in Host LAN IP. It is the address listed in that computer’s network settings, often beginning with 192.168 or 10. Don’t use an internet/public address.
  4. Copy the full text in Session invite and send it privately to the other person.

Join a session

  1. Open the identical WAV in the desktop app and wait for its check to finish.
  2. Open Share, paste the invite and choose Join session.
  3. Read the replacement prompt: joining loads the host’s layers in place of your current layers. Save anything you need first.

Edits update after the host accepts them. If two people change the same revision at once, Tonalia keeps the accepted change and offers the rejected proposal as a download for manual recovery. If its name ends in .tonalia, rename it to .tonalia.json before using Open project.

Undo and redo are disabled while sharing. A remote change stops playback. Leaving keeps the latest layers on your computer; the host’s leave button also closes the session.

Use this only on a trusted local network: session traffic is not encrypted. Keep the invite private, don’t open router ports, and allow local firewall access only if you intend to host. Cross-computer and network setups may need further testing.

Use Tonalia offline

The installed app works without an internet connection. There’s no account, activation step for editing. Download the installer first and finish installing needed system components. Optional sound-separation packs need a one-time online setup; once installed, those models also run locally. The included 48 kHz speech denoiser needs no extra model download.

  1. Keep your WAV and project files on the computer. Files stored only in a cloud service must be downloaded or marked available offline first.
  2. Disconnect Wi-Fi or the network.
  3. Open Tonalia, edit, save a project and export a new WAV as usual.

The browser editor needs a connection to load its files. Audio processing still happens locally, but use the installed app when you need reliable offline access. The website doesn’t ask you to upload a recording.

What to expect from 0.4.1

This is a working development release. Keep original files and test an edit before using it for a finished job.

  • Files: mono or stereo WAV/RF64, 8–192 kHz. MP3, AAC and other compressed formats need conversion elsewhere. More than two channels aren’t supported.
  • Exports: new 32-bit or 64-bit float WAV files, at the original rate and channel count.
  • Clean-up: initial gate, hum, short-click and speech tools. Advanced healing, declipping and automatic room-echo removal aren’t implemented. Captured noise profiles are available; adaptive noise tracking is not.
  • Workflow: one recording per project, up to 64 layers. There’s no multitrack timeline, audio recording or plug-in hosting.
  • Playback: uses the default audio output. There’s no in-app device chooser or ASIO support yet.
  • Sharing: experimental trusted-local-network sessions, not hosted internet collaboration.
  • Browser: use a recent desktop browser. If it can’t stream an export directly to disk, exports are limited to 256 MiB; install the desktop app for larger work.

Read the earlier editing engine details. Tonalia does not claim complete Adobe Audition feature parity.

If something isn’t working

The app won’t open.

Check that the installer matches your computer and chip. See the Windows or Mac installation steps above for publisher prompts. On Linux, check the required system libraries and AppImage instructions. Download a fresh copy if the file may be damaged.

My recording won’t open.

This version opens WAV/RF64 files, not MP3 or AAC. A filename ending in .wav doesn’t guarantee the file is a supported WAV. Use mono or stereo audio and check that the file is fully downloaded.

I can’t hear anything.

Check your system’s default audio output, headphones and volume, then the listening slider in Tonalia. Click the time ruler before the end of the recording and press Space. Try Original to check whether an edit is making the selection too quiet. In a browser, click Play yourself to allow audio.

The picture changed, but the sound didn’t.

A selection alone doesn’t change audio. Create a gain or restoration layer, make sure its eye button is on, and listen in Result mode. Display brightness, frequency scale and analysis detail don’t change the audio.

Speech denoise is unavailable.

The included speech tool requires a 48 kHz file and supports one neural speech layer per project. It uses a time selection across all frequencies. Check the source information and any error shown in the app.

I hear clicks or unwanted changes.

Reduce the amount of processing and soften the selection edges where the tool supports it. Compare Original, Result and Removed. A short-click repair needs intact samples on both sides and a selection no longer than 10 ms.

My project asks for the original WAV.

A project stores edits, not audio. Select the unchanged original recording, not an exported result or a converted copy. If the recording was changed elsewhere, restore the original from your backup.

I can’t find my recovery history.

History is local to the app or browser profile. Clearing data, using another browser or switching profiles won’t carry it across. Open an explicitly saved project and its original WAV instead.

The app is slow or playback breaks up.

Version 0.4.1 evaluates dense brush strokes more efficiently and recovers brief render queue gaps. A device failure or a sustained stall still stops playback with an error. Check your default audio device, close other busy audio apps and reduce analysis detail if needed. Speech clean-up and separation can take preparation time.

Export failed or the next app can’t read it.

Choose a new filename in a writable local folder and make sure there is enough disk space. This version exports float WAV, not MP3 or 16-bit WAV. If the receiving app needs another format, convert the exported file there. In the browser, try a shorter range or the desktop app.

A shared session won’t connect.

Both computers need the desktop app, the identical WAV and a trusted local network. Check the host’s private IP, that LAN access was enabled before hosting, and the local firewall. Keep the host app open. Don’t use router port forwarding.

Still stuck? Report a problem on GitHub. Include your operating system, the Tonalia version, what you clicked and the error message. You don’t need to post a private recording.
