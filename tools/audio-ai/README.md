# Local audio intelligence

The desktop **Separate sounds** workspace runs ONNX models on this computer. It never uploads recordings. Model installation downloads public weights and verifies their pinned SHA-256 checksums. The core editor still works without these optional packs.

## Use

1. Open a WAV from disk, then choose **Separate sounds** in the header.
2. Choose the whole recording or a time selection (up to 10 minutes per job).
3. Install the selected AI pack once. Python 3.11 or newer must be installed; Tonalia creates an isolated environment automatically. On Windows the environment, models and completed results live in `%LOCALAPPDATA%/Tonalia/ai-v1`. Current packs total approximately 1.11 GiB, plus runtime dependencies. Installed packs work offline. An update to the detector preserves verified music/extraction packs.
4. **Auto separate** runs a PANNs sound-event detector over the audio, selects up to eight nonredundant source classes above the chosen score threshold, and extracts them with AudioSep. When music is detected it uses the dedicated six-stem music model. Event timing provides a soft activity prior; joint spectral masks allocate shared energy between tracks and reduce bleed. Unknown, rejected and leftover material stays in **Unassigned residual**. This is a bounded source estimate, not a promise to discover every recorded object.
5. **Find sounds** runs the same trained 527-class AudioSet detector and shows measured event times and model scores. There are no example presets, default sound descriptions or forced top-three matches. **Extract [sound]** creates actual WAV audio directly; **Separate detected sounds** runs the complete automatic pipeline. **Inspect region** is a separate selection-only action. Higher detection thresholds yield fewer suggestions; silence or uncertain clips can yield none. Model scores are not calibrated guarantees.
6. **Music stems** produces vocals, drums, bass, guitar, piano, other instruments, and a residual. **Isolate a sound** accepts up to eight descriptions and produces estimated tracks plus a residual. Suggested description buttons appear only after analysis of the same recording. **Spectral cleanup** controls competition between source estimates; setting it to zero preserves the model's raw estimates. Cleanup can suppress detail, so compare the residual and adjust by ear.
7. **Tiny clicks** finds abrupt changes relative to their local background. It extracts spectral excess in those events instead of copying all frequencies inside a time rectangle, retaining the continuous background in the residual. The detector does not infer the object that made a click.
8. Preview any track, open it in the spectral editor, or export all tracks to a new folder. Exports are 32-bit float WAVs at the original sample rate/channel count. Selected-range stems start at the selection; `separation.json` records the source offset, detector events, source scores, cleanup setting and exact asset identities. The models internally use 44.1 kHz (music) or 32 kHz (detection/extraction); original-rate export is resampled model output.

Jobs are cancellable. Processing uses the original recording, independently of the spectral layer stack. Opening a generated track follows the editor's existing unsaved-edit confirmation. Generated tracks are audio files, not embedded layers in a `.tonalia.json` project; export them before clearing the AI cache. Recent job choices remain in the open workspace; completed job manifests persist in local storage.

## Models and attribution

- [Meta HT-Demucs](https://github.com/facebookresearch/demucs), MIT; [StemSplit's six-source ONNX export](https://huggingface.co/StemSplitio/htdemucs-6s-onnx), pinned revision `49df9b6989cf2150840ea65b0bef77a2e471b678`. Guitar and piano separation is experimental; model heads do not cover every instrument.
- [AudioSep](https://github.com/Audio-AGI/AudioSep), MIT, Copyright Xubo Liu; [ailia-models ONNX export and inference reference](https://github.com/axinc-ai/ailia-models/tree/master/audio_processing/audiosep). The STFT, normalization and complex-mask reconstruction follow that export's interface. Tonalia applies it per channel using overlapped chunks.
- [PANNs](https://github.com/qiuqiangkong/audioset_tagging_cnn), MIT, Copyright Qiuqiang Kong; [ailia sound-event detector export/reference](https://github.com/ailia-ai/ailia-models/tree/master/audio_processing/audioset_tagging_cnn). The fixed seven-second, 32 kHz model predicts framewise scores for all 527 AudioSet classes. Tonalia processes overlapping windows, joins event boundaries, removes redundant parent detections, and abstains below the selected threshold. The unchanged [AudioSet ontology](https://github.com/audioset/ontology) is by Google Inc. / Dan Ellis, CC BY-SA 4.0; attribution is included in `AUDIOSET-ATTRIBUTION.txt`. AudioSep's tokenizer comes from pinned [RoBERTa](https://huggingface.co/FacebookAI/roberta-base) assets.

The upstream MIT license texts are included alongside this file and copied into the installed AI support directory. Model files are not committed to this repository or bundled in the base application. See `models.json` for exact download URLs, sizes and SHA-256 identities.

Separation cannot recover information that was not recorded. Masking, similar sources, reverberation, short events and low signal-to-noise ratios limit both identification and isolation. Raw target estimates can overlap; optional joint spectral cleanup reduces duplicated energy. The residual compensates so the tracks sum to the input within float precision. This is not arbitrary all-source discovery, speaker diarization, bird-species identification or a guaranteed reconstruction of studio multitracks.

## Checks

Run `python tools/audio-ai/test_worker.py` in the AI virtual environment. To include actual inference, set `TONALIA_TEST_AI_MODELS` to the installed `ai-v1` directory. Tests cover quiet stereo transients, silence/steady-tone rejection, spectral transient extraction, reduced cross-bleed, chunk/recording edges, rate/layout preservation, actual model outputs, prompt-dependent extraction and automatic telephone/speech separation. Set `TONALIA_TEST_AI_FIXTURE` to the upstream `R9_ZSCveAHg_7s.wav` reference clip to run the automatic detection/extraction contract. `node tests/native/auto-separation.mjs` exercises analysis-driven suggestions, direct extraction, automatic splitting and abstention through the desktop interface. Native smoke tests exercise the desktop job bridge, cancellation, result preview and export.
